## What is Linear Regression?

Linear Regression is a Machine Learning algorithm used to predict a numerical value based on past data.

Simple Definition

Linear Regression finds a relationship between two variables and predicts future values.

Easy Example
Study Hours	Marks
2	40
4	60
6	80

The pattern is:

✅ More study hours → Higher marks

If a student studies 5 hours, the model may predict 70 marks.

Real-Life Uses
🎓 Predict student marks
🏠 Predict house prices
💼 Predict sales revenue
🚗 Predict fuel consumption
Advantages

✅ Easy to understand

✅ Fast and simple

✅ Good for beginners

Limitations

❌ Works best with straight-line relationships

❌ Not suitable for complex data

Summary

Linear Regression is a Machine Learning technique that uses past data to find a pattern and predict future numerical values.
