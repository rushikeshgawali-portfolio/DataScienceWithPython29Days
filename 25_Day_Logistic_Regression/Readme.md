## 🎯 What is Logistic Regression?

Logistic Regression is a Machine Learning algorithm used to predict categories or Yes/No outcomes.

Simple Definition

Logistic Regression predicts which category something belongs to.

Unlike Linear Regression, which predicts numbers, Logistic Regression predicts choices or classes.

## 🧠 Easy Example

Imagine a college wants to predict whether a student will Pass or Fail.

Study Hours	Result
2	Fail
3	Fail
5	Pass
7	Pass

Pattern:

✅ More study hours → Higher chance of passing

If a student studies 6 hours, the model predicts:

Pass ✅

## 🔄 Linear Regression vs Logistic Regression
Linear Regression	Logistic Regression
Predicts numbers	Predicts categories
Example: Marks = 75	Example: Pass/Fail
Output = Numerical Value	Output = Yes/No, True/False

## 🌍 Real-Life Applications

🏥 Disease Prediction

Patient → Disease or No Disease

🛒 Customer Purchase Prediction

Customer → Buy or Not Buy
