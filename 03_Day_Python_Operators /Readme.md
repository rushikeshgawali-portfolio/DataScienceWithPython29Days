## ➕ Arithmetic Operators
Arithmetic operators are used to perform mathematical operations.

| Operator | Name | Description | Example (a = 10, b = 3) | Result |
| :--- | :--- | :--- | :--- | :--- |
| + | Addition | Adds values | a + b | 13 |
| - | Subtraction | Subtracts right from left | a - b | 7 |
| * | Multiplication | Multiplies values | a * b | 30 |
| / | Division | Returns float quotient | a / b | 3.333... |
| % | Modulus | Returns division remainder | a % b | 1 |
| ** | Exponentiation | Calculates power | a ** b | 1000 |
| // | Floor Division | Returns integer quotient | a // b | 3 |

## 📝 Assignment Operators
Assignment operators are used to store values in variables.

```python
x = 5       # Basic assignment
x += 3      # Equivalent to x = x + 3 (x becomes 8)
x -= 2      # Equivalent to x = x - 2 (x becomes 6)
x *= 2      # Equivalent to x = x * 2 (x becomes 12)
x /= 4      # Equivalent to x = x / 4 (x becomes 3.0)
