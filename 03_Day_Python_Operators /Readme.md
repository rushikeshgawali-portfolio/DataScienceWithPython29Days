## ➕ Arithmetic Operators
Arithmetic operators are used to perform mathematical operations.

| Operator | Name | Description | Example (a = 10, b = 3) | Result |
| :--- | :--- | :--- | :--- | :--- |
| + | Addition | Adds values | a + b | 13 |
| - | Subtraction | Subtracts right from left | a - b | 7 |
| * | Multiplication | Multiplies values | a * b | 30 |
| / | Division | Returns float quotient | a / b | 3.333... |
| % | Modulus | Returns division remainder | a % b | 1 |
| ** | Exponentiation | Calculates power | a ** b | 1000 |
| // | Floor Division | Returns integer quotient | a // b | 3 |

## 📝 Assignment Operators
Assignment operators are used to store values in variables.

```python
x = 5       # Basic assignment
x += 3      # Equivalent to x = x + 3 (x becomes 8)
x -= 2      # Equivalent to x = x - 2 (x becomes 6)
x *= 2      # Equivalent to x = x * 2 (x becomes 12)
x /= 4      # Equivalent to x = x / 4 (x becomes 3.0)


## 🔍 Relational (Comparison) Operators
Relational operators compare two values and evaluate to a Boolean (True or False).

| Operator | Meaning | Example (a = 10, b = 5) | Result |
| :---: | :--- | :--- | :---: |
| == | Equal to | a == b | False |
| != | Not equal to | a != b | True |
| > | Greater than | a > b | True |
| < | Less than | a < b | False |
| >= | Greater than or equal to | a >= 10 | True |
| <= | Less than or equal to | b <= 5 | True |

---

## 🧠 Logical Operators
Logical operators are used to combine conditional statements:

* *and: Returns True if **both* statements are true.
* *or: Returns True if **at least one* statement is true.
* *not*: Reverses the result (turns True to False and vice versa).

```python
x = 7
print(x > 5 and x < 10)  # True (Both conditions are true)
print(x > 10 or x < 10)  # True (At least one condition is true)
print(not(x > 5))        # False (Reverses True to False
